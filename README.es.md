# Certificación de Bases de Datos Relacionales de freeCodeCamp

[ English ](README.md) | [ Español ](README.es.md)

Una colección de mis soluciones a los proyectos requeridos para la **certificación de Bases de Datos Relacionales** de **freeCodeCamp**. Cada proyecto vive en su propia carpeta e incluye su propia documentación y código fuente.

El propósito de este repositorio es presentar las soluciones de manera organizada, para que cada proyecto pueda revisarse y ejecutarse de forma independiente.

---

## Proyectos

| # | Proyecto | Descripción |
|---|---|---|
| 01 | [Celestial Bodies Database](./01-celestial-bodies-database) | Un volcado de base de datos PostgreSQL para modelar un universo de horror cósmico con galaxias, estrellas, planetas, lunas y anomalías. |
| 02 | [World Cup Database](./02-world-cup-database) | Un volcado de base de datos PostgreSQL del torneo de la Copa Mundial desde 2014, incluyendo Cuartos de Final, Semifinales, Tercer Lugar y Final para 2014 y 2018. |
| 03 | [Salon Appointment Scheduler](./03-salon-appointment-scheduler) | Una base de datos PostgreSQL y aplicación CLI para gestionar citas de salón, con diseño de esquema, inserción de datos y un script de reservas. |
| 04 | [Periodic Table Database](./04-periodic-table-database) | Un volcado de base de datos PostgreSQL con información sobre elementos químicos (número atómico, símbolo, masa, puntos de fusión/ebullición, tipo). |
| 05 | [Number Guessing Game](./05-number-guessing-game) | Un volcado de base de datos PostgreSQL que registra usuarios y sus juegos de adivinanza, almacenando nombres de usuario y la cantidad de intentos para encontrar un número secreto. |

---

## Tecnologías

- **PostgreSQL** (`psql`)
- Scripts de Bash para consultas interactivas en CLI
