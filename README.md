# freeCodeCamp Relational Database Certification

[ English ](README.md) | [ Español ](README.es.md)

A collection of my solutions to the projects required for the **freeCodeCamp Relational Database Certification**. Each project lives in its own folder and includes its own documentation and source code.

The purpose of this repository is to present the solutions in an organized way, so each project can be reviewed and run independently.

---

## Projects

| # | Project | Description |
|---|---|---|
| 01 | [Celestial Bodies Database](./01-celestial-bodies-database) | A PostgreSQL database dump for modeling a cosmic horror-themed universe with galaxies, stars, planets, moons, and anomalies. |
| 02 | [World Cup Database](./02-world-cup-database) | A PostgreSQL database dump for the World Cup tournament since 2014, including Quarter-Finals, Semi-Finals, Third Place, and Final matches for both 2014 and 2018. |
| 03 | [Salon Appointment Scheduler](./03-salon-appointment-scheduler) | A PostgreSQL database and CLI application for managing salon appointments with schema design, data insertion, and a booking script. |
| 04 | [Periodic Table Database](./04-periodic-table-database) | A PostgreSQL database dump storing information about chemical elements (atomic number, symbol, mass, melting/boiling points, type). |
| 05 | [Number Guessing Game](./05-number-guessing-game) | A PostgreSQL database dump that tracks users and their guessing games, storing usernames and the number of guesses taken to find a secret number. |

---

## Tech Stack

- **PostgreSQL** (`psql`)
- Bash scripts for interactive CLI queries
